# Project Plan — cave

## Roadmap

Rationale: `docs/architecture_design.md` › Delivery Approach.

- [x] Phase 1: Backend Spike & Decision
  - Outcome: Bubblewrap (`bwrap`) selected as isolation backend (9.28 ms startup overhead, rootless, clean tmpfs masking). Direct terminal inheritance selected (native signals/TTY passthrough, no relay). Rust selected as CLI implementation language (<2ms overhead, single static binary, `CommandExt::exec` process replacement). Loosely coupled to external `bwrap`. Reusing host `/tmp` supported via `--dir /tmp`. Spike script preserved at `vdesign/utils/spike-bwrap.sh`.
- [x] Phase 2: Walking Skeleton — `cave claude`
  - Outcome: Implemented in Rust (`src/cli.rs`, `src/policy.rs`, `src/bwrap.rs`). Embedded profiles (`src/profiles.toml`) with Claude Code profile (RW state `~/.claude/`, `~/.claude.json`, RO runtime `~/.local/share/claude`). Mount order rule enforces defaults → profile → CWD → `--dir` / `--ro-dir` overrides. Private tmpfs for `/tmp`, `/run`, `/var/tmp`, and `$HOME`. Sensitive paths hidden. Host environment sanitized (`SSH_AUTH_SOCK`, `DBUS_SESSION_BUS_ADDRESS` unset). Direct terminal inheritance via `execve`. Hardened boundary tests (12 unit, 11 boundary tests green), typed state entries with valid JSON seeding (`init = "{}"`), and raw OsString passthrough. Initial `--doctor` diagnostics check bwrap availability and AppArmor unprivileged user namespace sysctls; sandbox DNS and `/var/run` symlink checks deferred to Phase 3. Live interactive verification confirmed on host terminal (direct TTY, SIGWINCH resize, colors, Ctrl-C, Ctrl-Z/fg); a setting changed inside `cave claude` (`/config`) persisted directly to native host `claude`, confirming live host state writes on existing inode without triggering kernel mount-point `EBUSY`. Added startup overhead measured at 7.37 ms (budget < 100ms).
- [x] Phase 3: Agent Profiles & Diagnostics
  - Outcome: Added embedded profiles for `agy` (`~/.gemini` RW state permitting runtime `agentapi` execution bridge generation), `aider` (`~/.aider` RW state, `~/.aider.conf.yml` RO runtime), and shell profiles (`sh`, `bash`, `zsh`). Added `~/.local/share/uv` to `ro_home` defaults so uv tool symlinks resolve. Profile mount loop renders `state` before `runtime` so read-only subpath binds override parent read-write state directories. Unknown-agent warning emitted to stderr with `--dir` hint; suppressed for shells. User config file (`${XDG_CONFIG_HOME:-$HOME/.config}/cave/profiles.toml`) layered over embedded defaults with append semantics, downgrade-by-re-declaration, and fatal located parse errors. Config is loaded once and passed in as `&ConfigData`: neither `build_mount_plan` nor `prepare_host_state` reads config, and `prepare_host_state` is the only host write. Completed `cave --doctor` diagnostics: verifies `bwrap` availability, unprivileged user namespaces, AppArmor restriction, `/var/run` symlink to `/run`, sandboxed `/etc/resolv.conf` nameserver presence, non-fatal external DNS lookup, and prints loaded config sources with effective merged profile table. Verified live interactive session persistence across host and cave boundaries for `agy` and `claude`. Test suite expanded to 17 unit tests and 19 boundary tests (36 tests, all passing, 0 clippy warnings). Measured release startup overhead: 8.96 ms (budget < 100 ms).
- [x] Phase 4: Arch Linux Packaging & Distribution
  - Outcome: Created Arch Linux VCS package specification in `packaging/arch/PKGBUILD` for `cave-git` (provides/conflicts with `cave`, runtime dependency `bubblewrap`, build dependencies `cargo`/`git`). Dynamic `pkgver()` supports git tags and commit count fallbacks. Formalized project licensing with root MIT `LICENSE` and enhanced `Cargo.toml` metadata (description, repository, homepage, license). Reconciled `README.md` with exact installation semantics (git branch build vs local cargo testing), clarified default `~/.config` inheritance isolation, and removed privileged `.npmrc` from config examples. Validated package build with `makepkg` pulling from GitHub into `cave-git-*.pkg.tar.zst`, verified with `tar -tf` containing `/usr/bin/cave`, documentation, license, and `/usr/share/doc/cave/profiles.toml.example` from `examples/profiles.toml`.
- [/] Phase 5: SSH via the host ssh-agent
  - Rationale: `docs/architecture_design.md` › SSH.
